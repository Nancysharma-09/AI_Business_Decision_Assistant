# 🤖 AI Business Decision Assistant

### GenAI-Powered Retail Analytics & Business Intelligence

An end-to-end GenAI-powered business intelligence project that allows users to ask retail business questions in natural language and receive data-driven insights.

The assistant converts natural-language questions into safe, read-only SQL queries, executes them against a cloud-hosted MySQL-compatible database, and transforms the results into concise business insights.

## 📌 Project Overview

Traditional business analysis often requires users to understand SQL or navigate multiple dashboard filters.

This project provides a conversational interface where users can simply ask questions such as:

- Which country generated the highest revenue?
- What was the best-performing month?
- Which products generated the most revenue?
- Who are the top customers?
- How many orders were generated by the United Kingdom?
- What is the total revenue?

The system interprets the question, generates a read-only SQL query, retrieves the required data, and converts the result into a business-friendly insight.

🔐 SQL Safety

Because the application generates SQL dynamically, a safety validation layer is included before executing queries.

Only read-only SELECT queries are allowed.

The application blocks operations such as:

INSERT
UPDATE
DELETE
DROP
ALTER
TRUNCATE
CREATE
REPLACE
GRANT
REVOKE

This prevents the AI-generated query from modifying the underlying business data.

☁️ Cloud Database

The retail database is hosted using TiDB Cloud, which provides MySQL-compatible database functionality.

The cloud migration was validated against the original local database using key business metrics including:

Total transaction count
Unique customer count
Total revenue
Country-level revenue

The results matched the original dataset analysis.
